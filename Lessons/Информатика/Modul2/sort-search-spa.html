11. клас · Информатика

Какво е сортиране?

  • Дефиниция: Процедура за подреждане на елементи
    — възходящ (1,2,3…) или низходящ ред (…3,2,1)
  • Защо е важно?
    За четими резултати, стандартизация на данни и оптимизиране на търсенето
  • Пример от реалния свят: Телефонен указател, речник, класация от НВО

🫧 Метод на мехурчето (Bubble Sort)

Идея: Сравняваме съседни елементи и разменяме, ако трябва. Най-голямото "изплува" накрая.

5,12,3 → 5,3,12
5,3 → 3,5
→ 3,5,12 ✓

O(n²) — квадратна сложност

for(int i = n-2; i >= 0; i--)
  for(int j = 0; j <= i; j++)
    if(array[j] > array[j+1])
    {
      int tmp = array[j];
      array[j] = array[j+1];
      array[j+1] = tmp;
    }

🎯 Пряка Селекция (Selection Sort)

Идея: На всяка стъпка намираме най-малкия оставащ елемент и го поставяме на правилното место.

Пример: 5,12,3,9 → 3,12,5,9 → 3,5,12,9 → 3,5,9,12

O(n²) — квадратна сложност

✓ Брой размени: максимум n-1

for(int i = 0; i < n-1; i++)
  for(int j = i+1; j < n; j++)
    if(array[i] > array[j])
    {
      int tmp = array[i];
      array[i] = array[j];
      array[j] = tmp;
    }

⚡ QuickSort (Хоор, 1959)

Идея: Избира "пивот" елемент. Всички по-малки отиват вляво, по-големите — вдясно. Рекурсия!

pivot = 8

[5,3,1] 8 [12,9,10]

→ [1,3,5] 8 [9,10,12]

O(n log n) среден случай

O(n²) най-лош случай

📌 C# Array.Sort() използва QuickSort

Тони Хоор: "Грешките... са моята грешка, извинете"

🔀 MergeSort (Сливане)

Идея: "Разделяй и владей" — разполови масива рекурсивно до единични елементи, после слей сортираните части.

[5,3,9,1] → [5,3] [9,1]
→ [5][3] [9][1]
→ [3,5] [1,9]
→ [1,3,5,9] ✓

O(n log n) — гарантирано!

⚠️ Изисква допълнителна памет O(n)

✓ Стабилен алгоритъм — запазва реда на равни елементи

🔍 Линейно Търсене

Идея: Проверяваме всеки елемент един по един докато намерим търсения или стигнем края.

O(n) — линейна сложност

✓ Работи с несортирани масиви

for(int i = 0; i < n; i++)
  if(array[i] == x)
    return i;
return -1;

🎯 Двоично Търсене (Binary Search)

Условие: Масивът трябва да е сортиран!

Идея: Сравни с средния елемент. Ако търсеният е по-малък — търси вляво, иначе — вдясно. Половини!

O(log n) — логаритмична!

1 000 000 елемента → максимум 20 стъпки

int left=0, right=n-1;
while(left <= right){
  int mid=(left+right)/2;
  if(array[mid]==x) return mid;
  if(x < array[mid])
    right = mid-1;
  else
    left = mid+1;
}
return -1;

🃏 Fisher-Yates Shuffle

Алгоритъм за случайна пермутация — обхожда масива отзад напред и разменя всеки елемент с произволен друг преди него.

"Генерирането на случайни числа е твърде важно, за да бъде оставено на случайността."
— Робърт Ковю

Сложност: O(n) — линейна
