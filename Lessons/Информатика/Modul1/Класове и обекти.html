Класове и обекти

Информатика - Модул 1

След този урок ще можеш да:
  • обясниш разликата между клас и обект;
  • опишеш свой клас с полета, свойства, методи и конструктор;
  • създаваш обекти с new и да разбираш какво се случва при r2 = r1;
  • избираш подходящ модификатор за достъп и добро име.

Клас и обект

Представи си формичка за курабии. Формичката не е курабия – тя е образецът. С нея можеш да изрежеш много курабии, всяка със собствена глазура. В програмирането:

Клас = формичката

  • описва какви данни и какво поведение ще има един вид обекти;
  • пише се веднъж;
  • е нов тип данни, като int или string.

Обект = курабията

  • конкретен екземпляр (инстанция) на класа;
  • създава се с new, по време на изпълнение;
  • има собствени стойности на данните.

Вече си ползвал готов клас от .NET – DateTime:

DateTime peterBirthday = new DateTime(1996, 11, 27);
DateTime mariaBirthday = new DateTime(1995, 6, 14);

Console.WriteLine($"Peter: {peterBirthday:d-MMM-yyyy}");
var mariaAfter18Months = mariaBirthday.AddMonths(18);   // метод на обекта
TimeSpan diff = peterBirthday.Subtract(mariaBirthday);
Console.WriteLine($"Maria older by: {diff.Days} days");

peterBirthday и mariaBirthday са два различни обекта от един и същ клас. Методите (AddMonths, Subtract) работят върху данните на конкретния обект.

Членове на класа

Ето прост клас Rectangle. Кликни върху подчертаните части на кода, за да видиш какво означават.

Избери част от кода

Обяснението ще се покаже тук.

ЧленКакво правиПример
ПолеПроменлива в класа, пази данни. Обикновено е private.private int _width;
СвойствоКонтролиран достъп до данните чрез get / set.public int Width { get; set; }
МетодДействие, което обектът може да извърши.public int CalcArea()
КонструкторЗадава началното състояние при new.public Rectangle(...)

Създаване на обекти

var r1 = new Rectangle(30, 20, "white");
var r2 = new Rectangle(15, 15, "green");

Console.WriteLine($"r1 area: {r1.CalcArea()}");   // 600
Console.WriteLine($"r2 area: {r2.CalcArea()}");   // 225

r2.Width = 20;                                   // променяме само r2
Console.WriteLine($"r2 area: {r2.CalcArea()}");   // 300

При new се заделя памет за нов обект и се изпълнява конструкторът. Достъпът до членове е с точка: обект.Член. Промяната на r2 не засяга r1 – всеки обект има свое състояние.

Модификатори за достъп

МодификаторКой има достъп
publicВсеки, отвсякъде
privateСамо кодът вътре в същия клас (по подразбиране за членовете)
protectedКласът и неговите наследници
internalВсичко в същия проект (assembly)

Защо свойства, а не публични полета?

Свойството може да пази данните валидни. Това е инкапсулация:

public class Rectangle
{
    private int _width;                      // поле – скрито отвън

    public int Width                         // свойство – контролиран достъп
    {
        get => _width;
        set
        {
            if (value <= 0)
                throw new ArgumentException("Width must be positive");
            _width = value;
        }
    }
}
Опитай в Лабораторията Включи и изключи „Валидация в setter“ и пробвай да зададеш ширина 0.

Класовете са референтни типове

Променливата r1 не съдържа самия обект, а референция (адрес) към него. Затова присвояването копира адреса, а не обекта: 

var r1 = new Rectangle(30, 20, "white");
var r2 = r1;            // r2 сочи към СЪЩИЯ обект
r2.Width = 50;

Console.WriteLine(r1.Width);   // 50 !
Често срещана грешка var r2 = r1; не създава нов обект. Нов обект се създава само с new. Виж го на живо в Лабораторията – бутонът „Втора променлива към този обект“.

Добри практики

  • Имената на класове и методи са в PascalCase: Rectangle, CalcArea.
  • Давай описателни имена: BankAccount, не BA или Class1.
  • Полетата са private, достъпът е през свойства и методи.
  • Един клас – една ясна отговорност.

Накъде след това: ООП

Класовете и обектите са основата на обектно-ориентираното програмиране, което стъпва на три идеи: инкапсулация (скриваме детайлите), наследяване (преизползваме клас) и полиморфизъм (един интерфейс, различно поведение).

Обобщение

  • Класът определя структура и поведение; обектът е конкретна инстанция.
  • Полетата/свойствата пазят данните; методите реализират поведението.
  • Конструкторът задава първоначалното състояние при new.
  • Класовете са референтни типове: = копира референцията, new създава обект.
  • Именувай класовете с ясни, описателни имена в PascalCase.
